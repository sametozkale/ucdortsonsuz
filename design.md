# Design System — ucdortsonsuz.com

Referans yapı: [Curated Supply](https://www.curated.supply/) — editorial, border-first, minimal shadow.

## Color Tokens

### Neutrals (foundation)
- `--color-bg`: #FAFAF7 — warm off-white, sayfa arka planı
- `--color-bg-alt`: #F4F3EE — sticky filter bar / subtle section
- `--color-surface`: #FFFFFF — kart yüzeyi
- `--color-surface-muted`: #F7F6F2 — hover/empty state
- `--color-border`: #ECEAE4 — kart, divider
- `--color-border-strong`: #D8D6CF — input, focus ring base
- `--color-text-primary`: #111111
- `--color-text-secondary`: #5C5C58
- `--color-text-tertiary`: #8A8A85 — disclaimer, captions
- `--color-text-inverse`: #FAFAF7

### Accent
- `--color-accent`: #1A1A1A (siyah, CTA fill)
- `--color-accent-hover`: #000000
- `--color-link`: #111111 (underline ile ayrışır)
- `--color-focus-ring`: #111111 @ 30% alpha

### Semantic
- `--color-success`: #2F7D5B
- `--color-warning`: #B8862B
- `--color-danger`: #B23A3A
- `--color-info`: #3A6EB2

### Overlay
- `--color-overlay-soft`: rgba(17,17,17,0.04)
- `--color-overlay-medium`: rgba(17,17,17,0.12)
- `--color-overlay-strong`: rgba(17,17,17,0.48)
