# Hero video

Place the landing hero background file here:

- **Filename:** `hero.mp4`
- **Recommended:** H.264, muted loop-friendly, 1920×1080 or similar, under ~15 MB for web

The site reads this path from `HERO_VIDEO_URL` in `lib/constants.ts`.

If the file is missing, the hero falls back to the book cover poster image.
